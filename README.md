# TaraCommute

**A navigational app for DAVAO CITY commuters**

Project attribution: Alton Ralph Buera — Buera Global Navigational Services Ltd.

TaraCommute helps Davao City residents and visitors explore transportation choices, find places, and prepare for safer trips. DC Bus is one transport option; it is not the whole app.

## Current starter package

Included:
- Home, Commute, Explore, Reports / Activity, and Profile tabs
- Visible Emergency shortcut with clear 911 guidance
- Jeepney / Multicab, DC Bus [FREE], Tricycle, and TNV / Motorcycle Taxi choices
- All nine supplied DC Bus routes and AM/PM stop sequences
- Route selector and stop list
- OpenStreetMap map display (map display only; not live traffic or turn-by-turn navigation)
- Optional Supabase initialization using build-time values
- Starter Supabase SQL migration
- GitHub Actions workflow to build a debug APK

Not yet implemented or verified:
- Live GPS tracking and permissions
- Geocoded DC Bus stop coordinates and accurate road geometry
- Bus positions and arrival estimates
- Verified jeepney/multicab routes and fares
- Live traffic provider
- Real TNV booking integrations
- Emergency dispatch integration
- Full directory data, incident grouping, moderation, and production account flows

The app intentionally does not invent coordinates, fares, bus positions, traffic, or emergency dispatch confirmations.

This source package is designed to be opened as a Flutter project. A complete native Android Gradle wrapper is normally generated by Flutter's `flutter create` command. Since this starter is prepared without running Flutter in this environment, follow the README's Android-only setup steps before the first GitHub Actions build.

## Android platform files

The source package keeps the app code separate from generated Android build files. The GitHub Actions workflow checks whether `android/` exists and, if it does not, generates the Android project files in the temporary GitHub build workspace. This lets you start the first APK build without a computer or emulator. The generated folder is not automatically committed back to your repository.

## Supabase setup

1. Create a Supabase project.
2. Open **SQL Editor** and run `supabase/migrations/0001_initial_schema.sql`.
3. In Project Settings → API, copy the Project URL and the **publishable key** (or legacy anon key).
4. Add these GitHub repository Actions secrets:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
5. Never put the service-role key in this app, GitHub Actions secrets used for client builds, or public source code.

The app can start without Supabase secrets; it will show local starter mode. Supabase initialization alone does not mean login, reports, or database features are complete.

## GitHub Actions APK build

The workflow is `.github/workflows/android-apk.yml`.

1. Open the repository's **Actions** tab.
2. Choose **Build TaraCommute Android APK**.
3. Tap **Run workflow**.
4. Open the completed workflow run.
5. Under Artifacts, download `tara-commute-debug-apk`.
6. Extract the ZIP and install `app-debug.apk` on your Android phone.

A debug APK is for testing only. A signed release build and security review are required before public distribution.

## Map and data safety

OpenStreetMap tiles are used for the map background. This does not provide live traffic. The map's initial view is only a city-level viewing position, not a bus stop or route coordinate. Do not use the stop list for passenger navigation until every stop has been geocoded and checked against the actual road network.

DC Bus AM sequences are the supplied source sequence. PM is generated by reversing that sequence, as specified in the handover. Check the official DC Bus source again before public release.

## Development approach

Make a backup before major changes. Add one feature at a time. Run Flutter analysis and tests, then build the APK with GitHub Actions. Do not describe untested features as working or production-ready.
